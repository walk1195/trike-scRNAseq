# TriKE scRNAseq Analysis

This repository contains all code written for the analysis of TriKE canine scRNAseq samples (_n=4_).

## Background

Tri-specific natural killer engagers (TriKE) are novel immunotherapeutic agents that utilizes a combination protein immune engager which binds to NK cells, guiding them to specifically target cancer cells. Here, we performed single-cell RNA sequencing on PBMCs taken from two dogs (with hemangiosarcoma) treated with TriKE (150mg/kg dose), who both showed elevated NK and/or T cell presence post-treatment. For each dog, one sample was taken PreTx and the other 2 weeks post-TriKE (1 day after last injection).

We are interested in determining, at the single-cell level, the extent to which TriKE has an impact on the transcriptional and functional profile of the T-cell compartment in these dogs.
